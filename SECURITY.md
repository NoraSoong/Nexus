# Security Policy

## Supported Versions

Nexus is a pre-alpha project. Security fixes are made against the latest commit on `main`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting:

<https://github.com/NoraSoong/Nexus/security/advisories/new>

If private reporting is unavailable, contact the maintainer at
<nora.soong@outlook.com>. Include a clear description, reproduction steps, affected
version or commit, and any mitigation you have identified. Do not include credentials,
private materials, or customer data.

You can expect an acknowledgement within seven days. Nexus is local-first, but reports
involving the MCP Helper, material access boundaries, Keychain handling, or model
provider requests are especially welcome.
